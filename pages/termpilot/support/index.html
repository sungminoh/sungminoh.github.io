Connecting

The connection fails or times out

  • Check that the hostname and port are reachable from your iPhone or iPad — a server on a private network needs VPN (e.g. Tailscale) or a local Wi-Fi connection.
  • For servers on your local network, allow Local Network access for TermPilot in iOS Settings → Privacy & Security → Local Network.
  • Key authentication: make sure the matching public key is in the server's ~/.ssh/authorized_keys.

Mosh does not start

  • mosh-server must be installed on the server and in the login shell's PATH.
  • The server's firewall must allow UDP ports 60000–61000.

tmux sessions don't appear

TermPilot lists sessions from the tmux found on the server. Install tmux there and make sure it is in the login shell's PATH.

Sync between devices

Hosts, groups, snippets and macros sync through your iCloud account. Passwords and keys sync through iCloud Keychain.

  • Both devices must be signed into the same Apple Account with iCloud turned on.
  • For credentials to follow, turn on iCloud Keychain (Settings → [your name] → iCloud → Passwords & Keychain). Without it, re-enter the password on each device.
  • Changes usually arrive within a minute; opening the app forces a check.

Voice input

Voice input runs on your device. The first use downloads a speech model, which needs an internet connection; you can remove models in Settings → Voice Input → Voice Settings.

Privacy

No data is collected. See the privacy policy.

접속

접속이 실패하거나 시간 초과돼요

  • 호스트명과 포트가 iPhone·iPad에서 닿는지 확인하세요. 사설망의 서버는 VPN(예: Tailscale)이나 같은 Wi-Fi 연결이 필요합니다.
  • 로컬 네트워크의 서버라면 iOS 설정 → 개인정보 보호 및 보안 → 로컬 네트워크에서 TermPilot을 허용하세요.
  • 키 인증이라면 짝이 되는 공개 키가 서버의 ~/.ssh/authorized_keys에 있어야 합니다.

Mosh가 시작되지 않아요

  • 서버에 mosh-server가 설치돼 있고 로그인 셸의 PATH에 있어야 합니다.
  • 서버 방화벽이 UDP 60000–61000 포트를 허용해야 합니다.

tmux 세션이 안 보여요

TermPilot은 서버의 tmux로 세션을 가져옵니다. 서버에 tmux를 설치하고 로그인 셸의 PATH에 있는지 확인하세요.

기기 간 동기화

호스트·그룹·스니펫·매크로는 iCloud 계정으로, 비밀번호와 키는 iCloud 키체인으로 동기화됩니다.

  • 두 기기가 같은 Apple 계정으로 로그인돼 있고 iCloud가 켜져 있어야 합니다.
  • 자격 증명까지 옮기려면 iCloud 키체인을 켜세요(설정 → [이름] → iCloud → 암호 및 키체인). 꺼져 있으면 기기마다 비밀번호를 다시 입력해야 합니다.
  • 변경은 보통 1분 안에 도착하며, 앱을 열면 즉시 확인합니다.

음성 입력

음성 입력은 기기에서 동작합니다. 처음 쓸 때 음성 모델을 내려받으므로 인터넷이 필요하며, 설정 → Voice Input → Voice Settings에서 모델을 지울 수 있습니다.
